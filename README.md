# AI-Powered Employee Financial Health Advisor

An end-to-end Machine Learning and Generative AI application that predicts employee financial health and generates personalized financial reports using XGBoost and LangChain.

---

## Overview

Employee financial well-being plays a significant role in productivity and long-term financial stability. This project leverages Machine Learning to assess an employee's financial health based on income, expenses, savings, investments, and engineered financial indicators.

The prediction generated by the XGBoost model is transformed into a structured financial profile, which is then analyzed by a Large Language Model (LLM) using LangChain to generate personalized financial reports containing financial insights, risk assessments, and actionable recommendations.

The project follows a modular architecture that clearly separates the Machine Learning prediction pipeline from the AI-powered report generation system.

---

## Key Features

- Predicts employee financial health using an optimized XGBoost classification model.
- Generates structured employee financial profiles from model predictions.
- Produces AI-generated financial reports using LangChain.
- Provides personalized financial insights and risk assessments.
- Utilizes engineered financial metrics to improve predictive performance.
- Modular architecture enabling easy scalability and future feature integration.
